## End state

### Announcement

- AgentCulture has one direct agent control plane (culture-agents), one communication product (culture-chat), one workflow engine (culture-rules), and independently deployable experience apps (embodiment/Gwen): no duplicated harness or dispatch managers, no requirement that agents join chat, and no lost realtime or safety guarantees.

### After state

- On a single host, 'agents runs submit' hands a task to a TS core daemon and returns a durable run ID; the run can be listed, shown, attached to as a live event stream, steered mid-run and cancelled, against real harnesses, with no chat server running; run state is stored on disk and read back truthfully after the daemon restarts.

### Success signals

- With no chat server process running: submit returns a run ID in < 2 seconds; at least 2 real harnesses complete a submitted task; a steer sent mid-run changes the run's subsequent output in 1 of 1 scripted trials per steer-capable harness; cancel reaches the terminal state 'cancelled' in < 10 seconds; and after kill -9 of the daemon plus restart, 100% of previously submitted runs report a state and 0 report an invented success.
